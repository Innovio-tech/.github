# Getting help

- **Using or building an Innovio product**: start with the repository's `README.md` and its `docs/`.
- **How we build, test and ship**: [engineering-standards](https://github.com/Innovio-tech/engineering-standards)
  (members only).
- **A bug or a request**: work is tracked in each product's tracker or roadmap, not in GitHub Issues; ask the
  product's maintainers (its `CODEOWNERS`).
- **A security problem**: never in public. Follow [SECURITY.md](SECURITY.md).
