# Innovio-tech/.github

Organisation-wide GitHub defaults. GitHub uses a file here for every repository that does not
have its own copy, so product repositories should **not** copy these files.

| File | Used for |
|---|---|
| `.github/PULL_REQUEST_TEMPLATE.md` | Every new pull request |
| `.github/ISSUE_TEMPLATE/config.yml` | The "New issue" page |
| `SECURITY.md` | The Security tab and the vulnerability reporting link |
| `CONTRIBUTING.md` | The contributing link on issues and pull requests |
| `profile/README.md` | The organisation's public profile page |

This repository must be **public** for GitHub to apply the defaults. It holds no secrets.
The rules behind the templates live in
[engineering-standards](https://github.com/Innovio-tech/engineering-standards).
